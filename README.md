## 目录结构

- `notes/`：学习过程中的原子笔记和源码阅读记录。
- `labs/`：动手验证、实验过程和观察结果。
- `handbook/`：经过整理、可以系统表达的学习成果。
- `visuals/`：信息图及其可编辑源文件。
- `references/`：参考资料和引用索引。
- `templates/`：可复用的笔记、实验和信息图模板。
- `archive/`：已经失效或被替代的内容。

## 内容流转

内容通常从 `notes/inbox/` 开始，经过分类、验证和整理后，进入 `notes/concepts/`、`labs/` 或 `handbook/`。信息图统一保存在 `visuals/`。
